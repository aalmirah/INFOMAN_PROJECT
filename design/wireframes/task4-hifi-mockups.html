6. Developer Handoff

Implementation notes for frontend engineering, accessibility, responsive behavior, and role-based access control.

CSS color tokens

:root {
  --color-primary: #3D7584;
  --color-secondary: #89B8BF;
  --color-accent: #FCAFC1;
  --color-ink: #000000;
  --color-surface: #FFFFFF;
}

Typography scale

Family: Inter, Segoe UI, sans-serif

Page title: 24px / 1.5rem, weight 700

Section title: 18px / 1.125rem, weight 600

Body: 14px / .875rem, weight 400

Caption: 12px / .75rem, weight 500

Grid and elevation rules

Use a 4px spacing grid: 4, 8, 12, 16, 24, and 32px. Cards use 8px radius, 1px borders, white surfaces, and soft teal-tinted shadows. Active navigation uses the secondary teal only on the selected item.

Responsive breakpoints

Mobile: 375px single-column content.

Tablet: 768px, two-column card grids where space allows.

Desktop: 1440px fluid shell with a 1440px maximum content constraint.

Tables must scroll horizontally below tablet width.

Role-based access control matrix

CapabilitySuperAdminAdminRegular User
ModulesAllMostAssigned only
User ManagementAll accounts and actionsSuperAdmins hidden; Admin actions —; User actions activeRestricted
System SettingsVisibleHiddenHidden
Navigation stateLinks are flat by default; only the clicked/current item receives a solid active highlight.
