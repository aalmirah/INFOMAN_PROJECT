# Team Working Agreement & Standards

## 1. Team Working Agreement
* **Communication Channel:** Discord / Messenger group chat.
* **Meeting Schedules:** Weekly sprint syncs and daily brief updates.
* **Collaboration Expectations:** Be respectful, communicate early if delayed, and perform code reviews promptly.

---

## 2. Definition of Done (DoD)
A task or feature is officially **Done** when:
- [x] Code or documentation is written and reviewed locally.
- [x] Changes are committed to a feature branch with descriptive commit messages.
- [x] Pull Request (PR) is created and reviewed by at least one teammate / Scrum Master.
- [x] All merge conflicts are resolved and PR is merged into `main`.
- [x] Associated GitHub Issue status is updated to **Done** and closed.

---

## 3. Role Guide Summary
* **Scrum Master:** Coordinates repository settings, board management, and sprint workflow.
* **DB Administrator:** Manages ERD designs, SQL scripts, and database integrity.
* **UI/UX Designer:** Creates wireframes, design systems, CSS themes, and component layouts.
* **Developer:** Implements feature logic, API routes, and core codebase functionality.
* **Tester:** Tests features, verifies acceptance criteria, and logs bug reports.
